### **Gráfico Aceleração x 1/Massa Total**

#### **Requisitos**
Para executar o código e gerar o gráfico, certifique-se de ter os seguintes itens instalados:
  
- **Python 3.x**  
- Bibliotecas necessárias:
  - `numpy`
  - `matplotlib`
  
Você pode instalar as bibliotecas executando:  
```bash
pip install numpy matplotlib
```

---

#### **Como Rodar o Código**

1. **Baixe o script Python**: Salve o código em um arquivo chamado `grafico_aceleracao.py`.  

2. **Execute o script**: No terminal, navegue até a pasta onde o arquivo está salvo e digite:  
   ```bash
   python grafico_aceleracao.py
   ```  

3. **Visualização do Gráfico**: Após a execução, um gráfico com a tendência linear será exibido mostrando a relação entre a aceleração e o inverso da massa total.  

---

#### **Descrição do Código**
- O código lê os valores experimentais de massa e aceleração.
- Um gráfico é gerado plotando a aceleração em função de \(1/massa\).
- A inclinação da reta de tendência é calculada e comparada com a força resultante aplicada no experimento.
  
---

#### **Saída Esperada**
- Um gráfico com os dados experimentais e a reta de tendência.
- A inclinação da reta e a força resultante impressas no console, por exemplo:
  ```
  Inclinação da reta de tendência: 0.20 N  
  Força resultante aplicada: 0.196 N
  ```
